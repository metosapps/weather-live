Support

For questions, bug reports, accessibility feedback or privacy requests, email alendatofall@gmail.com.

Help us investigate

Include the Weather Live app version, Galaxy device model, Android version, your location or city if a forecast is wrong, and the steps that led to the problem. A screenshot can help, but remove private details first. Never send a password, purchase credential or full payment card number.

Common checks

  • If local weather is unavailable, check network access and location permission, or search for a city manually.
  • If alerts are missing, check notification permission and any alert settings in the app.
  • If a radar layer is blank, try another network or wait for the map provider to recover.
  • Weather Live is a new app package. Premium purchases from another app do not transfer automatically, and this package does not currently sell Premium products.
